# Grading Rules

- `A` requires authoritative, academic, or methodology-plus-dataset support that survives domain checks.
- `B` requires clean independent `third_party_report` support.
- `C` is first-party support with denominator or timeframe.
- `D` is first-party numeric support without denominator or timeframe.
- `E` is no number or no usable evidence.
- `claimed_change_pp` is the only numeric field used for mechanical noise-floor downgrades.
- Python recomputes every `grade_final`; model phases may propose grades but never treat them as final authority.
